# Smart Campus Management System

## About
Smart Campus is a web-based platform designed
to simplify campus activities.

## Features
- Attendance Management
- Campus Events
- Campus Facilities
- Announcements
- Responsive User Interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.

## Project Type
Hackathon Project
